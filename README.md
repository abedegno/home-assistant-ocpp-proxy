# OCPP Charge Proxy for Home Assistant

A self-contained native integration is being prepared here. It combines the OCPP
emulator/transparent relay and native HA entities without requiring an app or MQTT.

See the open pull requests for the reviewed implementation and validation results.
No native release has been published yet.

The existing optional standalone app remains at:
https://github.com/abedegno/ocpp_charge_proxy

This project is derived from that MIT-licensed codebase.
